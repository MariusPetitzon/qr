# QR party

Every QR code points to `https://mariuspetitzon.github.io/qr/?CODE`.

- `inhoud.js`: **the only file to edit.** Activity texts and decoy page variants. Click it on github.com, then the pencil icon, edit, and Commit. Live within about a minute.
- `gifs/01.gif … 10.gif`: one GIF per activity (upload via Add file → Upload files, in the `gifs` folder). A missing GIF is simply not shown.
- `codes.js`: which code leads to which page. Generated by `tools/maak_codes.py`; never edit it by hand.
- `tools/`: scripts that generate codes and the printable PDFs.

Never remove or change existing codes: they are on the printed cards.
